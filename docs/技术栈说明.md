# 技术栈说明

## 运行环境

- Python 3.11；
- 项目统一使用上层课程目录中的 `.venv`；
- `requirements.txt` 保存核心依赖，`requirements_full.txt` 保存完整环境快照。

## 数据获取与存储

| 工具 | 用途 |
|---|---|
| `utils/findata_lib.py` | 课程统一数据接口，内部使用 Baostock、AkShare 等来源 |
| DuckDB | 保存资产信息、日线、国债收益率和交易日历，并通过 SQL 读取 |
| pandas | 表格整理、日期对齐、滚动计算与结果输出 |
| NumPy | 数值运算和向量化计算 |

数据库文件为 `Assignment1/data/data.duckdb`。分析代码只从 DuckDB 读取已清洗数据，数据更新统一通过模块 1 的下载、清洗和校验脚本完成。

## 统计与金融计算

| 工具 | 用途 |
|---|---|
| SciPy | 分布拟合、正态性检验和 Nelson–Siegel 数值优化 |
| statsmodels | OLS、Newey–West 稳健标准误和回归诊断 |
| pandas / NumPy | 收益率、滚动波动率、滚动相关性、久期和回测计算 |

主要口径见 `Assignment1/任务说明.md`，包括收益率定义、252 日年化、共同交易日对齐、零息债计价和压力测试情景。

## 可视化与页面

- 所有图表使用 Plotly，不使用 matplotlib 截图；
- 研究页面采用离线 HTML，由 Python 预计算数据和图表，Jinja2 生成页面，少量原生 JavaScript 负责控件联动；
- Plotly.js 在最终 HTML 中只嵌入一次，使页面能够脱机打开；
- 报告所需 SVG 或 PNG 由 Plotly 导出；静态导出需要 Kaleido 及其浏览器运行条件。

纯 HTML 页面不直接连接 DuckDB。数据或模型参数变化后，应重新运行构建脚本生成 HTML，以保证结果可复现。

## 代码组织原则

- 数据访问、分析计算、回测和可视化分层组织；
- 公共计算函数提供类型注解和 docstring；
- 具有状态和生命周期的逻辑，例如回测引擎和页面构建器，使用类封装；
- 图表函数只接收整理后的数据并返回 Plotly `Figure`，不在绘图函数中读取数据库；
- 所有输出由代码生成，不手工修改统计表、图表数据或 HTML 中的结果。

## 核心依赖

| 包 | 用途 |
|---|---|
| `duckdb` | 数据库存储与 SQL 查询 |
| `pandas`, `numpy` | 数据处理和数值计算 |
| `scipy`, `statsmodels` | 统计检验、优化与回归 |
| `plotly` | 交互图和静态图 |
| `Jinja2` | 单文件 HTML 页面模板 |
| `kaleido` | Plotly 静态图片导出 |
| `akshare`, `baostock` | `findata_lib.py` 的数据源依赖 |
