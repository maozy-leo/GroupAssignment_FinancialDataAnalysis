# 第一次小组作业 Proposal

## 1. 项目目标与整体思路

本项目将三人小组视为一个小型资产配置研究团队，为一笔“五年后到期、目标稳健增值”的资金设计并检验股债配置方案。研究不预设某种策略一定最优，而是比较不同策略在收益、波动、最大回撤、交易成本和临近到期风险上的取舍。

项目围绕三个问题展开：

1. 中国股票与债券的收益分布、波动率和相关性是否稳定？
2. 利率曲线、久期和凸性如何影响债券资产在压力情景下的表现？
3. 固定 60/40、风险平价和目标日期策略，哪一种更适合五年期限的稳健资金？

研究流程为：真实数据获取与 DuckDB 入库、数据质量检查、权益与固收分析、无前视配置回测、稳健性检验、形成建议及局限性讨论。

## 2. 数据方案

原始数据计划从 2018-01-01 起获取，2018 年作为滚动波动率和相关性指标的预热期；正式分析与回测从 2019-01-01 开始。最终数据截止日取主要日频序列共同可用的最新交易日，并记录抓取时间和数据来源。

### 2.1 权益数据

- 上证50；
- 沪深300；
- 中证500；
- 中证1000；
- 创业板指；
- 科创50；
- 中证红利。

沪深300作为主回测股票代理，上证综指或其他宽基指数可作为作业要求和稳健性补充。不同规模、成长和红利指数用于比较收益厚尾、滚动波动率和股债相关性。

### 2.2 债券数据

- 中债综合财富指数；
- 1—3 年、3—5 年和 7—10 年国债财富指数；
- 政策性金融债财富指数；
- AAA 信用债财富指数；
- 可转债指数。

主回测使用综合国债或综合债券财富指数，期限分层和信用债数据主要用于解释利率风险、信用风险及稳健性。

### 2.3 利率数据

- 国债收益率曲线历史：3 月、6 月、1 年、3 年、5 年、7 年、10 年和 30 年；
- FDR007，若能取得可靠来源则补充实际 DR007；
- MLF 历史操作利率；
- AAA 中短期票据收益率曲线；
- 同期限 AAA 收益率减国债收益率得到的信用利差。

课程数据接口只返回真实在线数据；所有来源失败时显式报错，不使用本地回退或模拟数据。MLF 和精确 DR007 若课程接口不覆盖，将从官方来源单独整理并注明口径。

### 2.4 DuckDB 初步结构

计划设置以下核心表：

| 表名 | 内容 |
|---|---|
| `asset_index_daily` | 权益与债券指数的日度数值、类别和来源 |
| `yield_curve_daily` | 不同曲线、期限和日期的收益率 |
| `money_market_daily` | DR007/FDR007 等货币市场利率 |
| `policy_rate_events` | MLF 等政策利率变动记录 |
| `credit_spread_daily` | AAA 信用利差派生结果 |
| `data_catalog` | 字段、单位、数据源和口径说明 |
| `data_quality_summary` | 样本量、日期覆盖、缺失、重复和异常值 |

数据库采用长表结构，以日期和资产或曲线标识组成唯一键。原始值和派生值分开保存。

## 3. 各部分完成思路

### 3.1 数据工程

建立统一下载和清洗流程，将日期、代码、数值单位和数据来源标准化后写入 DuckDB。通过 SQL 检查记录数、年度交易日、重复记录和跨资产日期匹配，并重点核对 2024-09-30、2024-10-08 等极端交易日。

### 3.2 权益市场分析

计算主要指数日对数收益的均值、标准差、偏度、峰度和 Jarque–Bera 检验；使用 Plotly 展示收益分布与正态分布差异。进一步分析 60 日滚动年化波动率、指数间及股债间 120 日滚动相关性，并研究 2024 年 9—10 月脉冲行情对固定 60/40 配置的冲击。

### 3.3 固定收益分析

使用最新国债收益率曲线拟合 Nelson–Siegel 模型，解释水平、斜率、曲率和衰减参数。计算关键期限债券的久期与凸性，并在平行上移和曲线陡峭化情景下比较久期近似、久期加凸性近似与精确定价。使用 10 年期国债收益率变化解释债券指数收益，估计其利率敏感度。

### 3.4 配置与回测

比较全股、全债、固定 60/40、风险平价和目标日期策略，可增加“目标日期约束下的风险平价”作为扩展。回测采用月末信号、下一交易日调仓，月内允许权重自然漂移，并纳入单边 10 bp 交易成本。

主要指标包括年化收益、年化波动率、Sharpe、最大回撤、Calmar 和月度胜率。稳健性检验考虑季度与月度再平衡、不同股票代理、不同债券期限，以及最近五年子样本。

### 3.5 报告与局限性

报告以实际结果为依据提出配置建议，并重点讨论短样本、指数不可直接交易、收益率曲线情景简化、参数选择、交易成本和样本外失效风险。最终附上成员分工和 AI 工具使用声明。
