# 模块3：固定收益分析结果

数据全部从 `Assignment1/data/data.duckdb` 通过 SQL 读取。收益率使用小数口径，债券定价采用面值 100、年复利的零息债近似；回归标准误为 Newey–West HAC（最大滞后 5）。

## 3.1 Nelson–Siegel 曲线拟合

曲线日期为 **2026-10-16**。最优参数为：$\beta_0=0.023306$，$\beta_1=-0.011797$，$\beta_2=-0.010945$，$\tau=3.5593$；8 个期限点的 RMSE 为 **0.877 bp**。绝对残差最大的是 7 年期，残差为 -1.923 bp。

**结果说明什么：** $\beta_0$ 对应长期利率水平；$\beta_1$ 为负，说明短端低于长期水平；$\beta_2$ 描述中端弯曲；$\tau$ 控制曲率峰值位置及因子衰减速度。较低 RMSE 表明四参数曲线能简洁概括该截面。

**对资产配置有何影响：** 延长期限可能提高静态收益率，但也会显著增加利率敏感度；配置决策应同时看收益率曲线形状与久期风险。

## 3.2 久期和凸性

10 年期零息债的拟合收益率为 1.6359%，理论价格为 85.0217，修正久期为 9.8390 年，凸性为 106.4875。

**结果说明什么：** 在零息债假设下，麦考利久期等于期限；期限越长，修正久期和凸性越高，价格对收益率变化越敏感。

**对资产配置有何影响：** 长久期债券在利率下行时提供更高资本利得，但在利率上行时承担更大回撤。

## 3.3 利率压力测试

仅久期近似的最大绝对误差出现在 **平行下移100bp、10 年期**，为 55.408 bp；加入凸性后的最大绝对误差为 2.164 bp。跨全部期限和情景，凸性使平均绝对误差降低 **97.0%**。

**对资产配置有何影响：** 对含长久期债券的组合做压力测试时，应至少使用久期加凸性，重要决策则应采用精确重定价。

## 3.9 五年到期资金的久期匹配

以五年零息负债的修正久期为目标，3年/10年零息债杠铃组合的市值权重为 3年 **71.36%**、10年 **28.64%**，其一阶久期缺口为零。

该组合相对五年负债的精确盈余变化为：-100bp 时 0.052%；+100bp 时 0.045%。即使久期完全匹配，凸性差异仍会造成二阶盈余变化。

**配置含义：** 对五年后确定用途的资金，债券配置应以资产—负债久期缺口为核心，而不是只看债券权重。
