# Assignment 1 数据说明

## 1. 数据口径

- 数据获取日：2026-10-18。
- 最新交易日：2026-10-16。
- 原始日频区间：2018-01-01 至最新可用日期。
- 正式分析区间：2019-01-01 至股债主序列的最新共同交易日。
- 2018 年数据只用于 60/120 日滚动指标预热。
- 指数和 ETF 保存点位或前复权价格；国债收益率统一保存为小数。
- 缺失观测不跨日填充，收益只在同一资产相邻有效观测之间计算。

### 3.5 `trading_calendar`：交易日历表

| 字段 | 类型 | 含义 |
|---|---|---|
| `trade_date` | `DATE` | A 股交易日，主键 |

该表由沪深 300 的交易日期生成，共 2,130 个交易日，区间为 2018-01-02—2026-10-16。回测时通过与所用资产日线内连接取得共同交易日。

```sql
CREATE TABLE assets (
    asset_id VARCHAR PRIMARY KEY,
    asset_name VARCHAR NOT NULL,
    asset_class VARCHAR NOT NULL,
    symbol VARCHAR NOT NULL,
    source VARCHAR NOT NULL,
    return_type VARCHAR NOT NULL,
    tenor_bucket VARCHAR
);

CREATE TABLE index_daily (
    asset_id VARCHAR NOT NULL REFERENCES assets(asset_id),
    trade_date DATE NOT NULL,
    close DOUBLE NOT NULL CHECK (close > 0),
    PRIMARY KEY (asset_id, trade_date)
);

CREATE TABLE gov_yield_daily (
    trade_date DATE NOT NULL,
    tenor_years DOUBLE NOT NULL CHECK (tenor_years > 0),
    yield_decimal DOUBLE NOT NULL,
    PRIMARY KEY (trade_date, tenor_years)
);

CREATE TABLE yield_curve_snapshot (
    curve_date DATE NOT NULL,
    tenor_years DOUBLE NOT NULL CHECK (tenor_years > 0),
    yield_decimal DOUBLE NOT NULL,
    PRIMARY KEY (curve_date, tenor_years)
);

CREATE TABLE trading_calendar (
    trade_date DATE PRIMARY KEY
);
```

## 4. 代码与运行顺序

在项目根目录依次执行：

```bash
source ../.venv/bin/activate
python Assignment1/data/download_and_ingest.py
python Assignment1/data/clean_data.py
python Assignment1/data/validate_data.py
```

- `data_config.py`：数据路径、资产代码和字段映射。
- `download_and_ingest.py`：调用 `utils/findata_lib.py`，下载并原子写入 DuckDB。
- `clean_data.py`：执行类型转换、合法值过滤、去重和排序。
- `validate_data.py`：执行结构、范围、交易日和异常行情校验。
- `cleaning_summary.json`：清洗前后记录数。
- `validation_results.json`：完整校验结果、逐年交易日数和异常行情清单。

清洗规则、缺失分布、SQL 校验及异常行情核验见 [`数据质量报告.md`](数据质量报告.md)。
